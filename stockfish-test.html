Chess Move Classification Tester v1.09

Diagnostic build using full Stockfish 19 with native WDL output and position auditing.

Primary search: 100,000 nodes, MultiPV 1, one thread, 128 MB hash, UCI_ShowWDL enabled. The engine is reset with ucinewgame before each PGN.

This version deliberately removes the category-weight “accuracy” percentage. The output is for validating positions, evaluations, WDL loss and classifications.
