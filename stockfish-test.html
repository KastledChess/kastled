Chess Move Classification Tester v1.12.2.4

Diagnostic build comparing Stockfish's best move and the played move from the same pre-move position.

Primary searches: 100,000 nodes, MultiPV 1, one thread, 128 MB hash, UCI_ShowWDL enabled. Hash is cleared before each independent search. Bound-only results are retried at 200,000 nodes.

Book moves are listed as Book in the move table and summary. Every move is still analysed and contributes to continuous move and game accuracy. Great and Brilliant awards remain disabled until the core loss model is validated. Non-best moves where both continuations lose by forced mate remain unscored pending mate-loss calibration.
